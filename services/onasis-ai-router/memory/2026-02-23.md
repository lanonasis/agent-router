## 🚀 Deployment Checklist

### Deploy AI Router Security Patches to VPS
```bash
# On VPS
cd /path/to/onasis_ai_router
git pull  # Once repo is initialized
# OR manually copy updated files:
# - core/ai-service-router.js
# - core/unified-router.js
# - server.js
# - package.json

pm2 restart ai-router
pm2 save
```

### Configure Redis on VPS
```bash
# Install Redis
sudo apt install redis-server  # or brew on macOS

# Start Redis
redis-server --daemonize yes --protected-mode no

# Update service .env files:
REDIS_URL=redis://localhost:6379
RATE_LIMIT_STORE=redis

# Restart services
pm2 restart all
pm2 save
```

### Clear Auth Outbox Backlog
```bash
# Check outbox processor
pm2 logs auth-gateway --lines 100

# May need to restart outbox worker
pm2 restart auth-gateway-outbox
```
