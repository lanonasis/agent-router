Onasis Agent Haven is a self-hosted platform for building, deploying, and monitoring AI agents through one secure workspace.

- Provide a visual dashboard for creating agents from prompts, tools, models, and knowledge sources.
- Run agents locally or on private cloud infrastructure with configurable CPU, memory, and GPU limits.
- Add version control, rollback, environment variables, and reusable agent templates.
- Stream logs, traces, costs, and performance metrics with alerts and failure notifications.
- Enforce role-based access, encrypted secrets, audit trails, and sandboxed tool execution.
